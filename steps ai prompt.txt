Berikut adalah panduan prompt engineering bertahap yang saya susun khusus untuk SRS Penjadwalan SMK v3 ini. Saya pecah menjadi strategi arsitektur prompt, roadmap 10 tahap, dan template prompt siap pakai untuk setiap tahap.
1. Prinsip Dasar Prompting untuk SRS Kompleks
SRS ini memiliki 16 bab, ratusan spesifikasi teknis, dan multi-layer architecture (CI3 + MySQL + Bootstrap + jQuery + GA Engine). Jika diberikan sekaligus, AI akan mengalami:

    Context dilution: spesifikasi penting terkubur di tengah dokumen panjang.
    Halusinasi arsitektur: AI membuat asumsi sendiri soal relasi database atau alur GA.
    Output tidak konsisten: nama variabel, struktur folder, atau CSS class berbeda antar modul.

Solusi: Incremental Context Loading
Berikan hanya satu domain masalah per prompt, tapi selalu sertakan "kontrak global" (design token, naming convention, base structure) di awal setiap prompt.

TAHAP 5: GA Engine (Inti Algoritma)
plain

Lanjutkan. Kontrak global: [copy-paste]

TUGAS SAAT INI (referensi SRS Bab 16 - pseudocode fungsi kritis):
Buatkan library Algoritma Genetika di `application/libraries/GA_Scheduler.php`.

Spesifikasi wajib:
1. Representasi kromosom: array 2D [hari][slot] = id_penugasan
2. Hard Constraints (HC) yang dicek fitness:
   - HC-01: Guru tidak double-booked di slot sama
   - HC-02: Kelas tidak double-booked di slot sama  
   - HC-03: Ruangan tidak double-booked di slot sama
   - HC-04: Jam mengajar guru tidak melebihi jam maks/minggu
   - HC-05: Kelas hanya mendapat mapel sesuai penugasan
3. Soft Constraints (SC):
   - SC-01: Preferensi guru (hati-hati jika melanggar)
   - SC-02: Penempatan mapel praktikum di ruangan sesuai tipe
4. Operator: selection (tournament), crossover (order-based), mutation (swap slot)
5. Method publik:
   - `generate($id_tahun_ajaran, $generasi_maks = 500)`
   - `get_best_fitness()`, `get_best_schedule()`, `get_conflict_list()`

Gunakan data dari tabel: penugasan_guru, jam_pelajaran, kelas, ruangan.
Jangan buat view/UI di tahap ini, fokus pada library PHP murni.
Sertakan komentar penjelasan per fungsi.

4. Teknik Lanjutan untuk Hasil Sempurna
A. Context Anchoring
Di setiap prompt tahap ke-N, selalu ulangi 3-5 baris kontrak global (design token, naming convention, struktur folder). Ini mencegah AI "lupa" saat context window penuh.
B. Chain-of-Thought untuk GA
Untuk Tahap 5 (Algoritma Genetika), minta AI menuliskan:

    Struktur data kromosom
    Pseudocode fitness function
    Pseudocode crossover & mutation
    Baru kemudian kode PHP

Ini mencegah AI membuat alur GA yang salah.
